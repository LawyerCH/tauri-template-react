# UI 规范

任何视觉改动（页面、组件、样式、图表、图标排布）都走三道门，缺一道算没做完。

## 门 1：声明设计读法

动手写样式前，先输出一行：

> 设计读法：为 `<谁>` 做 `<什么界面>`，语气 `<克制 / 活泼 / 编辑感 / 仪器感>`，倾向 `<技术路线>`。
> dial：VARIANCE `x` / MOTION `x` / DENSITY `x`

| 场景 | VARIANCE | MOTION | DENSITY |
|---|---|---|---|
| 内部工具 / 数据台 | 2–4 | 1–3 | 6–8 |
| 桌面应用外壳 | 2–4 | 1–2 | 5–6 |
| 营销 / 引导页 | 7–9 | 5–8 | 3–5 |
| 阅读优先 | 3–5 | 1–3 | 2–4 |

没声明就写 CSS，视为返工。

## 门 2：加载设计方法

优先用全局技能：`design-taste-frontend` → `ui-ux-pro-max` → `frontend-ui-engineering`。
项目已有令牌与组件时，以本文件为准，技能只补方法，不覆盖令牌。

## 门 3：交付前逐条自检

见文末清单，回复里逐条写 PASS / FAIL，不许只写"已检查"。任一 FAIL 修完再交付。

## 令牌（唯一色源）

定义在 `src/styles/tokens.css`，通过 `@theme inline` 映射为 Tailwind 语义类。

| 角色 | 浅色 | 深色 | Tailwind |
|---|---|---|---|
| 页面底 | `#F6F6F5` | `#0D0D0D` | `bg-bg` |
| 面板 | `#FFFFFF` | `#141414` | `bg-paper` |
| 正文 | `#1A1A1A` | `#EDEDEB` | `text-ink` |
| 次级 | `#5C5C5C` | `#A3A3A0` | `text-ink-2` |
| 弱化 | `#8A8A8A` | `#6E6E6B` | `text-ink-3` |
| 分隔线 | `#E4E4E2` | `#2A2A28` | `border-line` |
| 强调 | `#B3261E` | `#E2574C` | `text-accent` / `bg-accent` |

规则：

- 只有灰阶 + 公文红两组色系。状态不靠颜色单独承载，用文字标签。
- 强调色只出现在三处：当前选中态、主按钮、页头 1px 分隔线。不得做背景块、图表填充。
- 红色文字必须 ≥ 4.5:1，更浅的红不能用于正文。
- 圆角全站 `rounded-sm`（2px）；不混用。
- 层级只用 1px 线与留白表达，不用阴影、不用渐变。
- 标题衬线（`font-serif`），正文无衬线，数字 `tabular` 等宽。

## 组件规则

- 优先用 `src/components/ui/` 现有组件；缺能力时先扩展它，不在页面里手搓同类。
- 按钮文案单行不换行（`whitespace-nowrap`）；同一意图全站一个措辞。
- 所有交互元素键盘可达，焦点环可见；禁止 `outline: none` 无替代。
- 加载态用与最终布局同尺寸的骨架，不用转圈图标糊弄。
- 错误内联展示在出错位置，禁止 `alert()`。
- 空状态必须说明"怎么产生第一条数据"。

## 18 条自检

| # | 检查项 | 判定 |
|---|---|---|
| 1 | 设计读法 + dial | 已声明 |
| 2 | 字号层级 | ≥ 3 级，不靠加粗硬撑 |
| 3 | 字重 | 只用 400 / 500 |
| 4 | 行宽 | 正文 ≤ 72ch |
| 5 | 数字排版 | 等宽 + 右对齐 |
| 6 | 强调色 | 全站 ≤ 1 个 |
| 7 | 对比度 | 正文 ≥ 4.5:1，大字号 ≥ 3:1 |
| 8 | 圆角一致 | 全站 2px |
| 9 | 无阴影无渐变 | 只用 1px 线 |
| 10 | 表格 | 表头吸顶、行高一致、hover 反馈 |
| 11 | 空状态 | 有，且说明产生方式 |
| 12 | 加载态 | 骨架尺寸与终态一致 |
| 13 | 错误态 | 内联展示 |
| 14 | 焦点态 | 键盘可达、环可见 |
| 15 | 双主题 | 浅/深都实际看过 |
| 16 | 响应式 | < 768px 单栏/折叠 |
| 17 | 文案 | 按钮单行、措辞统一 |
| 18 | `docs/design.md` | 已更新，截图归档 |

## 禁止项

- 未声明读法就写样式
- 蓝紫渐变、发光按钮、玻璃拟态
- 三等分等宽卡片堆一行
- emoji 当图标
- 纯黑 `#000` / 纯白 `#fff` 大面积铺底
- 数据台里用营销大字、超大标题
- 只做浅色不做深色
