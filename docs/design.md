# 设计说明

- 设计读法：为桌面工具类用户做模板应用外壳（侧栏导航 + 内容区 + 设置页），语气克制，倾向 Tailwind v4 + CSS 变量令牌
- dial：VARIANCE 3 / MOTION 2 / DENSITY 6
- 技术路线：Tauri 2 + React 19 + Vite 8 + Tailwind CSS 4（`@theme inline` 映射运行时变量）
- 强调色：`#B3261E`（深色 `#E2574C`），语义色不另设彩色，状态用文字标签表达
- 圆角策略：全站 2px（`--radius-*` 统一压平）

## 关键决策

- 为什么这样布局：桌面应用固定窗口，左侧常驻导航比顶部导航更省纵向空间，内容区单列避免多栏打断阅读。
- 为什么这样排信息层级：页头只放当前页标题 + 1px 红色分隔线；页面内标题用衬线，正文用系统无衬线，数字用等宽并右对齐，避免靠加粗堆层级。
- 为什么侧栏 768px 以下折叠为图标：Tauri 窗口最小 880px，折叠只服务于浏览器调试与被拖窄的临时场景，不引入抽屉与浮层。
- 放弃了哪些方案：
  - shadcn/ui：会带入成批 Radix 文件与默认审美，模板需要更薄的依赖面。
  - 顶部导航 + 内容居中卡片：桌面端会浪费横向空间，且容易滑向"三等分卡片"式模板。
  - 自研主题切换（`class` + 手动拼接）：改为单一 `data-theme` 属性，主题只可能来自一份 settings。

## 状态覆盖

- 空状态：任务页给出"怎么产生第一条数据"的说明，而不是一片留白。
- 加载态：M1 无异步数据，未引入骨架屏；M2 接入任务引擎时按最终布局尺寸补骨架。
- 错误态：目前无网络/IO 调用；M2 起内联展示在出错位置，不使用 `alert()`。
