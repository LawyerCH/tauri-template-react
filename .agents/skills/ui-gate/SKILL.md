# UI 三道门

依据 `docs/ui.md`。三道门缺一道算没做完。

## 门 1：声明读法（写第一行样式之前）

输出一行：

> 设计读法：为 `<谁>` 做 `<什么界面>`，语气 `<克制/活泼/编辑感/仪器感>`，倾向 `<技术路线>`。
> dial：VARIANCE `x` / MOTION `x` / DENSITY `x`

桌面工具类默认 `VARIANCE 2–4 / MOTION 1–2 / DENSITY 5–6`。
没声明就写 CSS，等于返工。

## 门 2：加载设计方法

按顺序取第一个可用的：`design-taste-frontend` → `ui-ux-pro-max` → `frontend-ui-engineering`。
项目已有令牌与组件，技能只补方法，不允许覆盖令牌。

## 门 3：交付前 18 条自检

逐条写 PASS / FAIL / N/A，附一句证据。任一 FAIL 先修再交付。

重点易错项：

| 项 | 常见错法 | 正确做法 |
|---|---|---|
| 字号层级 | 全靠 `font-bold` 区分 | 14/16/20 三档 + 12px 标注 |
| 字重 | 用 600/700 | 只用 400/500 |
| 强调色 | 主按钮、选中态、图表各用一种红 | 全站一个 `accent`，仅三处使用 |
| 圆角 | 按钮 8px、卡片 2px | 全站 `rounded-sm` |
| 层级 | 加阴影浮起 | 1px `border-line` + 留白 |
| 数字 | 左对齐比例字体 | `tabular` + 右对齐 |
| 空状态 | 一片空白 | 说明"怎么产生第一条数据" |
| 加载态 | 居中转圈 | 与终态同尺寸骨架 |
| 错误态 | `alert()` | 出错位置内联 |
| 焦点 | `outline: none` | 保留可见焦点环 |
| 深色 | 只调背景色 | 文字、分割线、强调色全套换 |
| 窄屏 | 横向滚动 | < 768px 单栏/折叠 |

## 令牌速查

只用这些语义类，不写裸色值：
`bg-bg` `bg-paper` `text-ink` `text-ink-2` `text-ink-3` `border-line` `text-accent` `bg-accent`
字体：`font-serif`（标题）、默认 sans（正文）、`tabular`（数字）。圆角只有 `rounded-sm`。

## 需要改视觉时

同步更新 `docs/design.md` 的"关键决策"与截图，截图放 `docs/shots/`。

## 输出

1. 设计读法一行
2. 改了什么（2–3 句）
3. 18 条自检表
4. 截图路径（浅色 / 深色 / 窄屏）

## 禁止

- 未声明读法写样式
- 蓝紫渐变、发光、玻璃拟态
- 三等分卡片堆一行
- emoji 当图标
- 大面积纯黑纯白
- 只做浅色不做深色
- 用"看起来更现代"当设计理由
